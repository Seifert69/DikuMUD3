# Archived zones

Zones taken out of the game, kept for their history. The build compiles only the zones
directly in `vme/zone/`, and the server loads only those in `vme/etc/zonelist`, so nothing
here is compiled or loaded.

- `rebirth.zon`: rebirth and morphing, part of the old guild path system (archived November 2026).
  A level 300 player who had 40 levels in each guild of their guild path could sacrifice heads,
  be reborn with a new race and guild path, and morph into a creature. No exit or teleport in any
  other zone led into it any more. Saved DILs from it load as inert placeholders, and objects
  from it turn into slime.
